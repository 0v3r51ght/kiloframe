# KiloFrame Capabilities

## Integrated Systems

### Superpowers
- Source: https://github.com/obra/superpowers
- 14 skills integrated for structured development workflows
- Includes: brainstorming, test-driven-development, systematic-debugging, writing-plans, executing-plans, subagent-driven-development

### Serena
- Source: https://github.com/oraios/serena
- IDE-like semantic code tools via MCP
- Symbol navigation, reference finding, rename operations
- Configured in `src/kiloframe/serena.py`

### Context7
- Source: https://github.com/upstash/context7
- Up-to-date library documentation lookup
- CLI-based and MCP support
- Configured in `src/kiloframe/context7.py`

## Optional Integrations

### GitHub MCP
- Source: https://github.com/github/github-mcp-server
- Authenticated repository operations
- Not required for local use

### Exa
- Source: https://github.com/exa-labs/exa-mcp-server
- Advanced research capabilities
- Optional when configured

### Firecrawl
- Source: https://github.com/firecrawl/firecrawl-mcp-server
- Web scraping and crawling
- Optional when configured

### Playwright
- Source: https://github.com/microsoft/playwright-cli
- Browser automation
- Primary implementation for web interactions
